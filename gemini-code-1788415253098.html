Ch. 1.3b: Evaluating Limits Algebraically

Review the five core reduction steps and algebraic techniques before testing your skills on the practice problems.

1. Recap Steps: Simplify / Reduction Method

  1. Evaluate argument first: Plug the target value directly into the expression.
  2. Check for indeterminate form: If direct substitution produces \(\frac{0}{0}\), evaluate further. Note: \(\frac{0}{0}\) does not mean the limit is undefined; it means our evaluation is unfinished. (The function has a hole in the graph, but the limit usually exists).
  3. Factor / Reduce / Simplify: Find common factors, multiply by conjugates, or combine fractions to reduce the expression.
  4. Re-evaluate the limit: Plug the target constant into the reduced expression.
  5. Confirm real number result: The resulting value is the limit.

2. Algebraic Techniques

I. Conjugate Method

If there is a sum or difference of 2 terms involving a radical in the numerator (or denominator), multiply both the numerator and denominator by the conjugate term.

Example 1: \(\lim_{x \to 4} \frac{6 - \sqrt{x+32}}{x - 4}\)
Multiply by \(\frac{6 + \sqrt{x+32}}{6 + \sqrt{x+32}}\).
Numerator: \(36 - (x + 32) = 4 - x = -(x - 4)\).
Cancel \((x - 4)\) to get \(\lim_{x \to 4} \frac{-1}{6 + \sqrt{x+32}} = -\frac{1}{12}\).

II. Common Denominator Method

If the expression contains complex fractions, simplify by finding a common denominator in the numerator, then cancel common factors.

Example 2: \(\lim_{x \to 0} \frac{\frac{1}{x+4} - \frac{1}{4}}{x}\)
Combine numerator: \(\frac{4 - (x + 4)}{4(x + 4)} = \frac{-x}{4(x + 4)}\).
Cancel \(x\): \(\lim_{x \to 0} \frac{-1}{4(x + 4)} = -\frac{1}{16}\).

3. The Squeeze Theorem

Definition: Suppose \(f(x) \le g(x) \le h(x)\) for all \(x\) in an open interval around \(a\). Suppose that: \[ \lim_{x \to a} f(x) = \lim_{x \to a} h(x) = L \] Then, the middle function is "squeezed" to the same limit: \[ \lim_{x \to a} g(x) = L \]

Example 3: Let \(h(x) = 1\) and \(f(x) = x^2 + 1\). If \(f(x) \le g(x) \le h(x)\), find \(\lim_{x \to 0} g(x)\).

• \(\lim_{x \to 0} f(x) = 0^2 + 1 = 1\)
• \(\lim_{x \to 0} h(x) = 1\)
Since both outer bounds approach \(1\) as \(x \to 0\), by the Squeeze Theorem: \[ \lim_{x \to 0} g(x) = 1 \]
